   497→// Pre-expiry disposal desk decisions — the triage layer between the desk's
   498→// candidates and its two disposal actions. A 'keep' marker flags fast-moving
   499→// near-expiry stock as deliberately sold through: no stock moves, nothing hits
   500→// the P&L, the batch stays fully sellable — it just stops looking like an
   501→// undecided problem every time the desk is reviewed. Cleared automatically
   502→// when a real disposal (write-off / supplier return) supersedes it.
   503→model DisposalDecision {
   504→  id                 String   @id @default(cuid())
   505→  medicineId         String   @unique
   506→  medicine           Medicine @relation(fields: [medicineId], references: [id], onDelete: Cascade)
   507→  action             String   @default("keep") // keep — selling through (future: other dispositions)
   508→  note               String?  // why the batch is kept — e.g. "fast mover, sells out in ~2 weeks"
   509→  daysLeftAtDecision Int?     // days-to-expiry snapshot when the decision was made
   510→  stockQtyAtDecision Int?     // on-hand snapshot when the decision was made
   511→  decidedByName      String?  // who made the call (display snapshot)
   512→  createdAt          DateTime @default(now())
   513→  updatedAt          DateTime @updatedAt
   514→}
